UI 模板選擇

兩個系統各三個方向，同一組元件（標題／身分列／功能導覽／輸入框＋按鈕／錯誤訊息／資料表）做出來的，可以直接互相比較。選定哪個，就把它的 CSS 搬進該系統的 public/style.css。

選之前先想兩件事。 一、戶外可讀性：這是白天在校園裡拿手機玩的遊戲，深色主題截圖好看，但正午太陽下反光會很痛苦——RPG 的「皇家典藏」和時空戰爭的「烈日行動」是唯二為這件事設計的。 二、時空戰爭要兼顧大螢幕：手機和大會集合投影 Dashboard 最好同一套視覺，「作戰儀表」是唯一放大就能直接上投影的。

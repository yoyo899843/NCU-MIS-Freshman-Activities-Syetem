UI 模板選擇

三個系統各三個方向，同一組元件（標題／身分列／功能導覽／輸入框＋按鈕／錯誤訊息／資料表）做出來的，可以直接互相比較。選定哪個，就把它的 CSS 搬進該系統的 public/style.css。

選之前先想兩件事。 一、戶外可讀性：這是白天在校園裡拿手機玩的遊戲，深色主題截圖好看，但正午太陽下反光會很痛苦——RPG 的「皇家典藏」和時空戰爭的「烈日行動」是唯二為這件事設計的。 二、時空戰爭要兼顧大螢幕：手機和大會集合投影 Dashboard 最好同一套視覺，「作戰儀表」是唯一放大就能直接上投影的。 三、股票系統的關鍵不是看盤：這個遊戲最容易卡人的是「申報存款 → 銀行審核 → 才能交易」，玩家看不懂自己卡在哪就會一直問關主。「銀行存摺」是唯一把這段做成進度條的。
九個模板都跑過無障礙檢查。 依 ui-ux-pro-max 技能規範重建：所有文字對比 ≥ 4.5:1（產出前用程式斷言，不合格就不會生成）、 內文與輸入框 16px（小於 16px 會讓 iOS 自動放大頁面）、觸控目標 ≥ 44px、3px 焦點環、 圖示全部改成 inline SVG、尊重系統的「減少動態效果」設定。 領先／落後、修復／破壞這類資訊除了顏色還加了文字與圖示，色盲也分得出來。

Stock System 賭大股票系統

三個模板共通的兩個決定。 一、不畫 K 線：K 棒需要開高低收四個價，這個遊戲一波只有一個收盤價；少於 4 個點也不該畫折線（ui-ux-pro-max chart 規則），首頁一律用「大數字＋漲跌幅＋各波價格」。 二、紅漲綠跌但不只靠顏色：台股慣例保留，每個漲跌都另外加三角形與正負號，紅綠色盲也分得出來。
模板 1

交易所看板

深藍黑底、金色數據、等寬報價列——券商看盤軟體的樣子。

  • ＋最像股市，數字對齊最好掃；排行榜放大就能直接投影
  • －戶外正午反光，讀新聞長文最累

# NCUMIS Camp 部署指引

給實際架設/更新伺服器時照著做的操作手冊。系統設計細節、資料庫 schema、API 設計請看 `PLAN.md`，這份文件只講「怎麼把它跑起來」。

## 系統架構總覽

五個獨立資料夾，各自一個 `docker compose` 專案，彼此不共用 DB：

| 資料夾 | 內容 | Host Port |
|---|---|---|
| `Portal/` | 玩家入口靜態頁（連結＋公告） | 9000 |
| `Time-Space Warfare/` | 時空戰爭遊戲主體（app + db） | 9001 |
| `PgAdmin/` | 全系統共用的資料庫管理介面，只給主辦本人用 | 9002 |
| `RPG System/` | 資管皇家學院數位探查儀（app + db） | 9003 |
| `Stock Game/` | 尚未開發，空資料夾 |  |

各系統的 `db` container 完全不對外，只有 app 跟 PgAdmin 會加入共用的 `ncumis-camp` 這個 external Docker network（給 Cloudflare Tunnel 連進來用）。

## 前置需求

- Docker Desktop（或 Docker Engine + Compose plugin）。
- Cloudflare Tunnel：**手動**在 Cloudflare dashboard 設定，本專案不包含 tunnel 設定檔。建議每個系統對應一個子網域（不要用路徑前綴），可避免 WebSocket 在路徑改寫時出問題。

## 首次部署

### 1. 建立共用網路（只需要做一次）

```bash
sudo docker network create ncumis-camp
```

### 2. 設定各系統的 `.env`

每個資料夾底下都有 `.env.example`，複製一份改成 `.env` 並填入真實密碼：

```bash
cd "Time-Space Warfare"
cp .env.example .env   # 編輯填入 POSTGRES_PASSWORD、JWT_SECRET

cd "../RPG System"
cp .env.example .env   # 編輯填入 POSTGRES_PASSWORD、JWT_SECRET（跟 Time-Space Warfare 各自獨立，不要共用同一組）

cd ../PgAdmin
cp .env.example .env   # 編輯填入 PGADMIN_DEFAULT_EMAIL、PGADMIN_DEFAULT_PASSWORD
```

`.env` 不會進 git（已在 `.gitignore` 排除），密碼不要寫死進 `compose.yml`。

### 3. 啟動順序

**`Time-Space Warfare` 跟 `RPG System` 都要先啟動，最後才啟動 `PgAdmin`**——PgAdmin 的 compose 需要引用這兩個系統各自建立的 `timewarfare-internal`、`rpg-internal` network，順序反過來會啟動失敗。`Portal` 沒有依賴關係，順序不拘。

```bash
cd "Time-Space Warfare"
sudo docker compose up -d --build

cd "../RPG System"
sudo docker compose up -d --build

cd ../PgAdmin
sudo docker compose up -d

cd ../Portal
sudo docker compose up -d
```

### 4. 跑資料庫 migration

**這是最容易漏掉的一步**——container 啟動不代表資料表已經建好，一定要手動跑一次，**兩個系統都要各自跑**：

```bash
cd "Time-Space Warfare"
sudo docker compose exec app node migrations/migrate.js

cd "../RPG System"
sudo docker compose exec app node migrations/migrate.js
```

會依序套用 `migrations/` 底下所有 `.sql` 檔（已經套用過的會顯示 `skip (already applied)`，可以放心重複執行）。沒跑這一步，任何需要碰資料庫的 API（登入、PK、題庫...）都會報 `relation "xxx" does not exist` 這種錯誤。

### 5. 建立管理員帳號（+ RPG System 的學派帳號）

沒有任何 HTTP 端點可以新增 admin 帳號，一律用伺服器上的 CLI script，**每個系統各自獨立一組 admin 帳號**：

```bash
docker exec timewarfare-app node scripts/create-admin.js <email> <密碼> "<顯示名稱>"
docker exec rpg-app node scripts/create-admin.js <email> <密碼> "<顯示名稱>"

# 範例
docker exec timewarfare-app node scripts/create-admin.js admin@example.com a-strong-password "主辦"
```

同一組 email 再執行一次就是**重設密碼**（不是報錯），忘記密碼時直接重新執行這行指令就好。密碼建議至少 8 碼（script 本身會擋太短的密碼）。

`RPG System` 另外要建 **5 組固定的學派帳號**（活動當天隊伍直接用這組帳密登入，不是自行註冊）：

```bash
docker exec rpg-app node scripts/create-school.js <username> <密碼> "<顯示名稱>"

# 範例
docker exec rpg-app node scripts/create-school.js dragon-house a-strong-password "赤龍學派"
```

登入網址：`https://<你的網域>/admin/login.html`（各系統各自的網域/子網域）。

### 6. 下載地圖圖磚（有校園實際 GPS 座標之後再做）

`Time-Space Warfare/public/tiles/` 需要活動前手動下載好（自行 host，不連外部 tile server）：

1. 打開 `Time-Space Warfare/scripts/download-tiles.js`，把 `BBOX` 改成校園實際的經緯度範圍（9 個交摺點座標 + 一點邊界）。
2. 在有 Node.js 的機器上執行：
   ```bash
   cd "Time-Space Warfare"
   node scripts/download-tiles.js
   ```
3. 確認 `public/tiles/` 底下有東西之後，重新 build/部署讓新的圖磚一起進到 image 裡：
   ```bash
   docker compose up -d --build app
   ```

### 7. 設定 Cloudflare Tunnel

在 Cloudflare dashboard 手動設定，ingress 規則指到各系統的 host port（見上面的 Port 對照表）。建議一個子網域對一個系統。

## 更新部署（程式碼有異動之後）

```bash
cd "Time-Space Warfare"
git pull                          # 或其他方式把新程式碼弄到伺服器上
docker compose up -d --build app  # 重新 build image、重啟 container
docker compose exec app node migrations/migrate.js   # 有新的 migration 檔一定要跑這行
```

`RPG System` 是同樣的流程（在 `RPG System/` 資料夾下執行）。`Portal`、`PgAdmin` 通常不太會變動，但如果有改也是同樣的 `docker compose up -d --build` 流程。

## 常見問題

**`error: relation "xxx" does not exist`**
Migration 沒跑。回到「首次部署 步驟 4」執行 `node migrations/migrate.js`。

**忘記 admin 密碼**
重新執行「首次部署 步驟 5」的 create-admin 指令，同一個 email 會直接覆蓋密碼。

**PgAdmin 啟動失敗（連不到 network）**
確認 `Time-Space Warfare` 跟 `RPG System` 都已經先啟動過（會分別建立 `timewarfare-internal`、`rpg-internal` network），再啟動 `PgAdmin`。

**想查某支隊伍的 PIN 碼**
PIN 是明碼存在資料庫（刻意不雜湊，方便隊輔忘記時查詢），用 PgAdmin 連進 `timewarfare` 資料庫查 `players` 表的 `pin` 欄位即可。admin 密碼、RPG System 的學派密碼則相反，是雜湊過的，查不到明碼，只能重設。

**忘記 RPG System 學派帳號密碼**
重新執行「首次部署 步驟 5」的 create-school 指令，同一個 username 會直接覆蓋密碼。

## 帳號指令速查

| 動作 | 指令 |
|---|---|
| 建立/重設 Time-Space Warfare admin 帳號 | `docker exec timewarfare-app node scripts/create-admin.js <email> <密碼> "<名稱>"` |
| 建立/重設 RPG System admin 帳號 | `docker exec rpg-app node scripts/create-admin.js <email> <密碼> "<名稱>"` |
| 建立/重設 RPG System 學派帳號 | `docker exec rpg-app node scripts/create-school.js <username> <密碼> "<名稱>"` |
| 跑資料庫 migration | `docker compose exec app node migrations/migrate.js`（在對應系統資料夾下執行） |
| 查玩家 PIN（Time-Space Warfare） | PgAdmin 連進 `timewarfare` 資料庫 → `SELECT display_name, pin FROM players;` |

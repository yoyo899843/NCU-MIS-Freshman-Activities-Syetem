# RPG System 部署指引

`資管皇家學院數位探查儀` 這個系統自己的部署手冊。整體多系統架構、共用網路、Cloudflare Tunnel 設定請看根目錄的 `部屬指引.md`；這份文件只講「這個資料夾自己怎麼跑起來」。系統設計細節（資料庫 schema、API 設計）請看根目錄的 `PLAN.md`。

## 前置需求

- Docker Desktop（或 Docker Engine + Compose plugin）。
- 共用的 `ncumis-camp` external network 已經建立（跟其他系統共用，一次性動作，見根目錄 `部屬指引.md`）。如果還沒建：
  ```bash
  docker network create ncumis-camp
  ```

## 首次部署

### 1. 設定 `.env`

```bash
cp .env.example .env
```

編輯 `.env`，填入：
- `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB`
- `JWT_SECRET`（建議用一長串隨機字串，例如 `openssl rand -hex 32`；跟 `Time-Space Warfare` 的 `JWT_SECRET` 各自獨立，不要共用）

`.env` 不會進 git（已在 `.gitignore` 排除）。

### 2. 啟動

```bash
docker compose up -d --build
```

會啟動 `rpg-app`（host port **9003**）跟 `rpg-db`（不對外，只在系統內部的 `rpg-internal` network）。

### 3. 跑資料庫 migration

**這是最容易漏掉的一步**——container 啟動不代表資料表已經建好：

```bash
docker compose exec app node migrations/migrate.js
```

會依序套用 `migrations/` 底下所有 `.sql` 檔（已套用過的顯示 `skip (already applied)`，可以放心重複執行）。沒跑這一步，任何碰資料庫的 API（登入等）都會報 `relation "xxx" does not exist`。

### 4. 建立帳號

沒有任何 HTTP 端點可以新增帳號，一律用 CLI script。

**管理員帳號**（後台用）：
```bash
docker exec rpg-app node scripts/create-admin.js <email> <密碼> "<顯示名稱>"

# 範例
docker exec rpg-app node scripts/create-admin.js admin@example.com a-strong-password "主辦"
```

**學派帳號**（5 組固定帳號，活動當天隊伍直接用這組帳密登入，不是自行註冊）：
```bash
docker exec rpg-app node scripts/create-school.js <username> <密碼> "<顯示名稱>"

# 範例（建立 5 組）
docker exec rpg-app node scripts/create-school.js dragon-house   a-strong-password "赤龍學派"
docker exec rpg-app node scripts/create-school.js phoenix-house  a-strong-password "朱雀學派"
docker exec rpg-app node scripts/create-school.js tiger-house    a-strong-password "白虎學派"
docker exec rpg-app node scripts/create-school.js tortoise-house a-strong-password "玄武學派"
docker exec rpg-app node scripts/create-school.js unicorn-house  a-strong-password "麒麟學派"
```

兩種帳號都是**同一個帳號/username 再執行一次就是重設密碼**（不是報錯），忘記密碼直接重新執行對應指令即可。密碼建議至少 8 碼（script 本身會擋太短的密碼）。

- 學派登入：`https://<你的網域>/login.html`
- 管理後台：`https://<你的網域>/admin/login.html`

### 5. 接上 PgAdmin（選用，方便主辦查資料庫）

回到根目錄的 `PgAdmin/compose.yml`，確認 `networks` 底下有 `rpg-internal`（已經接好），然後：

```bash
cd ../PgAdmin
docker compose up -d
```

之後在 PgAdmin 裡 Register Server 時，Host 填 `rpg-db`、Port `5432`、帳密對應這裡 `.env` 的 `POSTGRES_USER`/`POSTGRES_PASSWORD`/`POSTGRES_DB`。

## 更新部署（程式碼有異動之後）

```bash
git pull                          # 或其他方式把新程式碼弄到伺服器上
docker compose up -d --build      # 重新 build image、重啟 container
docker compose exec app node migrations/migrate.js   # 有新的 migration 檔一定要跑這行
```

## 常見問題

**`error: relation "xxx" does not exist`**
Migration 沒跑。執行 `docker compose exec app node migrations/migrate.js`。

**忘記管理員密碼**
重新執行 `create-admin.js`，同一個 email 會直接覆蓋密碼。

**忘記學派帳號密碼**
重新執行 `create-school.js`，同一個 username 會直接覆蓋密碼。學派密碼是雜湊過的（比照 admin，不是明碼），查不到原始密碼，只能重設。

**PgAdmin 連不到 `rpg-db`**
確認這個系統（`docker compose up -d`）已經先啟動過（會建立 `rpg-internal` network），再啟動/重啟 PgAdmin；`PgAdmin/compose.yml` 的 `networks` 底下要有 `rpg-internal`。
